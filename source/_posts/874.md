收到一份便宜报价，第一反应可能是另一家报贵了。收到一份贵报价，又担心便宜的那家做不出来。这种比较最容易卡住的地方，是两个人其实没有在报同一件事。

拿一个假设的角色外观委托来说，需求只有一句：“把这套衣服做进游戏。”作者甲理解为使用现有模型、替换一个固定角色；作者乙理解为重新制作衣服，并适配几种体型。报价差距再大，也不能直接说明谁在乱收费。

## 把两份报价放在同一张纸上

不必做复杂的表格，先对齐这些内容：

| 比较项 | 需要写清的内容 |
| --- | --- |
| 素材 | 由谁提供，能否用于这次委托，是否需要重做 |
| 使用范围 | 一个角色还是多个角色，固定体型还是多体型 |
| 运行环境 | 游戏版本、平台、前置工具及其版本 |
| 测试 | 只看静止画面，还是检查约定动作和场景 |
| 交付物 | 安装包、说明、可编辑工程分别是否包含 |
| 修改 | 包含哪些调整，新增要求怎样计费 |
| 维护 | 原环境问题如何处理，游戏更新后是否另算 |

如果其中一份没写，不要自行理解成“全包”，也不必立刻认定对方故意隐瞒。把缺项问出来，才有继续比较的基础。

## 最值得追问的是“不包含什么”

“包含制作和售后”听起来很完整，但不能直接拿来验收。

售后是教你安装一次，还是处理原版本里可复现的问题？交付以后发现袖子在某个动作下穿模，属于修改范围吗？换了体型以后出现同样的问题，又怎么算？这些比“能优惠多少”更影响最后花费。

有的低价方案把工程文件、额外配色和兼容测试分开收费。只要事先讲明白，并不一定不合理。你确实不需要那些内容，买精简方案反而更合适。

贵的方案也不天然更稳。如果对方只是把“专业团队”“高级定制”写得很满，却说不出对应交付物，仍然需要追问。

## 比价时别悄悄改需求

给第一位作者发的是一张图，给第二位作者补充了联机、可配置菜单和后续维护，回来只对比最终数字，结论很容易失真。

把需求整理成同一份文字，问几位有相关经验的作者。通过[Mod 定制页面](https://www.glossmod.com/custom-mod)发布需求时，也保留这份底稿。新增条件后，把新版补给前面的人，并说明希望按同一版本重新确认。否则你拿到的只是几轮不同聊天的结果。

也别把某位作者详细设计出的方案直接转交给别人压价。你可以比较自己的需求，但别人额外完成的设计和验证工作，不该默认成为免费招标材料。

## 最后比较的是总支出和剩余风险

初次报价低，却还得另找人补素材、写安装说明和修兼容问题，未必划算。初次报价高，但里面有你根本不需要的独占授权，也未必值得买。

问到最后，理想的状态不是“这家最便宜”，而是“我知道这笔钱覆盖到哪里，没覆盖的部分我也接受”。

两份报价仍然拿不准，就把其中差异最大的一项单独问清。是少做了一项适配，还是多给了一份工程文件？这个答案，往往比再问一次“最低多少”有用。
